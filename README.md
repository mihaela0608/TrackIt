# 🚀 TrackIt – Personal Finance Tracker

TrackIt is a full-stack web application designed to help users take control of their finances through clear tracking, goal setting, and insightful reports.

---

## ✨ Overview

Managing personal finances can be overwhelming. TrackIt simplifies this by providing a structured and intuitive way to:

* Track daily expenses
* Monitor financial habits
* Set and achieve financial goals
* Analyze spending through reports

---

## 🧠 Key Features

🔐 **Authentication System**

* User registration and login
* Secure access to personal financial data

💸 **Expense Tracking**

* Add and manage daily expenses
* Organized view of financial activity

🎯 **Financial Goals**

* Set personal goals (saving, budgeting)
* Track progress over time

📊 **Reports & Insights**

* Generate financial summaries
* Better understanding of spending behavior

---

## 🛠️ Technologies

**Backend**

* Java
* Spring Boot
* RESTful architecture

**Frontend**

* HTML
* CSS
* Thymeleaf

**Database**

* MySQL

---

## 🏗️ Architecture

The application follows a layered architecture:

* `Controller` – Handles HTTP requests
* `Service` – Business logic
* `Repository` – Data access
* `Model` – Core entities

---

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/mihaela0608/TrackIt.git
```

2. Open in your IDE (IntelliJ recommended)

3. Configure your MySQL database

4. Run the application:

```bash
TrackItApplication.java
```
